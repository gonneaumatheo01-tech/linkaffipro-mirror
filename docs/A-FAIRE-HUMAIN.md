# À faire par un humain (rien d'urgent, regroupé par phase)

## Depuis la phase 2
1. **Worker en Europe** : railway.com → projet linkaffipro → service worker → Settings → Regions → EU West (Amsterdam) → Deploy. Il est encore aux États-Unis (0,15 s par requête vers la base).
2. **Sauvegardes Railway** : projet linkaffipro → Postgres → Settings → Backups → activer Daily, Weekly et Monthly (voir `docs/SAUVEGARDES.md`).
3. **Comptes publicitaires** : dès qu'un compte TikTok Ads ou Meta Ads existe, le dire : les connecteurs API remplaceront l'import CSV.
4. **Vues par message** (nombre de vues Telegram) : nécessite une connexion avec le numéro de téléphone (code SMS), 5 minutes à faire ensemble.

## Phase 3
5. **Test de 5 minutes** (voir `docs/STATUS.md`) : vérifier le brief Telegram de 9h, activer une automatisation modèle, lancer un test A/B sur un envoi.
6. **Automatisations** : les règles modèles sont créées inactives ; relire les textes puis les activer (page Automatisations).
